FinanceHub App – PWA

Diese Version basiert auf deiner aktuellen FinanceHub-HTML-Datei und ist für die spätere Installation als App vorbereitet.

Wichtig: Die zentrale Synchronisierung zwischen PC und Handy ist noch NICHT eingerichtet. Dafür muss FinanceHub mit einer gemeinsamen Online-Datenbank verbunden werden.

Für die PWA-Installation muss die App über HTTPS ausgeliefert werden (z.B. eine Website/Hosting). Eine direkt per Datei geöffnetes index.html kann keine Service-Worker-App vollständig installieren.
